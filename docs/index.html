Install MyTV Launcher

A calm home screen for Android TV and Google TV. Choose the way that fits what you have at hand; it takes a few minutes.

With only the TV and its remote

No computer needed.

  1. On the TV, install Downloader (by AFTVnews) from the Google Play Store, or from its Play Store page.
  2. Open Downloader and type this code:
    3805347
  3. Allow Downloader to install apps when the TV asks, and install MyTV Launcher.
  4. Open MyTV Launcher. Its welcome screen guides you through the rest: language, weather, the Home button, a start-up app, Continue watching and profiles.

With a computer on the same Wi-Fi

Windows, Mac or Linux. Also sets up the extra permission, so the Home button works straight away.

First, on the TV:

  1. Settings → Device preferences (or System) → About → press OK on Build seven times.
  2. Developer options → switch on USB debugging, and Network debugging if it is there. Newer Google TVs (Android 12 and up): Wireless debugging instead, with a pairing code.
  3. Keep the TV on. The installer finds it on your network by itself.

Then on the computer:

Windows, in PowerShell:

irm https://raw.githubusercontent.com/tinteractive/MyTV/main/install/windows.ps1 | iex

Mac or Linux, in a terminal:

curl -fsSL https://raw.githubusercontent.com/tinteractive/MyTV/main/install/install.sh | bash

The installer finds the TV (or asks for its address), and you accept "Allow USB debugging?" on the TV. It installs nothing on the computer. Afterwards you can switch debugging off again.

With an AI coding agent

Claude Code or a similar agent on a computer on the same Wi-Fi.

Get the code from github.com/tinteractive/MyTV, open the folder with your agent and say "install MyTV Launcher on my TV". It follows AGENTS.md and changes nothing until you say yes.

Removing MyTV Launcher, and switching everything back: docs/ROLLBACK.md. Everything else: the project page.
